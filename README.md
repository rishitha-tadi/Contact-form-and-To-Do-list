# 📋 Contact Form and To-Do List

## 📌 Project Overview

This project is a simple and interactive web application developed using HTML, CSS, and JavaScript. It combines two useful functionalities in a single project — a Contact Form and a To-Do List application.

The Contact Form allows users to enter and submit their details, while the To-Do List helps users manage daily tasks efficiently. The project focuses on improving frontend development skills and understanding JavaScript DOM manipulation.

---

# 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript

## 📩 Contact Form Features

- User-friendly contact form  
- Input fields for name, email, and message

## ✅ To-Do List Features
